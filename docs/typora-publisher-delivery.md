# Typora 发布工具交付记录

根据用户修正，本次工具仅负责发布，写作继续在 Typora 进行。此前新增的编辑器、网页界面、草稿服务、测试、启动入口和常驻进程均已移除；相关内容未推送至 GitHub。

交付入口为根目录 `发布文章.cmd`：双击选择原稿，或把 `.md` 拖到入口上，在窗口检查图片并确认发布。支持沿用原稿分类或在窗口选择分类。

实现复用 mdast-util-from-markdown 的带位置语法树和 parse5 的 HTML 源位置，只改写实际图片节点，保留代码示例及 HTML 尺寸。图片采用内容指纹路径去重，复制原始字节，不重新压缩或绘制。Typora 的根路径设置、封面、中文路径及图片引用定义都纳入处理。

验证边界：

- 图片解析与原稿保护回归测试覆盖相对路径、绝对路径、file URL、中文空格、HTML、引用式、封面、代码块、缺图、伪图片和发布日期稳定性。
- 使用独立的本地 Git 远端执行真实 Hexo 构建和双分支发布；失败时两条远端分支及源文件均不改变；成功后发布 HTML 指向实际存在的图片，图片字节与原文件完全一致。
- Windows PowerShell 5.1 已实际运行窗口构造、异步文件检查和 UTF-8 输出读取；确认检查通过后发布按钮启用，并生成界面预览。
- 站点现有 10 个页面的构建及资源检查通过。资源检查增加相对路径及本机文件路径检查。
- 没有向线上发布任何测试文章。

限制：外链图片依赖原站；带本地外部资源的 SVG 或 HTML srcset 会明确停止，要求先处理。独立本机原稿不修改，直接选择博客源文件时会规范化链接并自动备份。
