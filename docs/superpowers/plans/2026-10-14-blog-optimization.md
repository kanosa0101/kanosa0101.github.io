# 博客基础优化实施计划

**目标：** 保留 Butterfly、现有背景和三句打字机文案，完成彩色首页文字、基础配置修复和可重复构建。

**设计：** 首页标题和副标题使用青、金、粉的静态文字渐变及暗色投影，保留打字机动画，不额外增加动画或第三方字体。样式通过 `source/css/custom.css` 注入，只作用于首页。个人资料不添加未经提供的信息。

**技术栈：** Hexo 8、Butterfly 5.5.2、CSS、Node.js 内置模块。

1. 增加 `tools/check-site.cjs` 生成站点检查脚本，先确认现有 favicon、Live2D 和页面类型问题能被发现（`scripts/` 由 Hexo 自动作为插件加载，不用于独立工具）。
2. 修复站点及主题配置、页面类型、作者链接；将个人资源复制到 `source/images/`，保留主题现有改动。
3. 实现首页彩色文字、手机排版与清晰键盘焦点。
4. 统一 npm 工作流，补充主题子模块声明、README、只读构建 CI；不提交或推送，不触发线上部署。
5. 运行完整构建和站点检查，在浏览器核对桌面及手机首页、导航、文章及深色模式，保存预览。

**验收：** 构建退出码为 0；所有生成页面的本地链接和资源存在；标签、分类、友链使用正确模板；Live2D 模型及关联资源存在；标题和打字机保留原文且显示多色，手机无水平溢出。
