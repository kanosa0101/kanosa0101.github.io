# 卡片与背景融合优化

## 设计及实现

- 保留原背景、首页彩色标题与打字机效果。
- 页脚和无背景图的文章、内页头部使用透明底色，消除默认蓝色背景；页脚使用浅暖色文字和暗色投影保证可读性。
- 文章列表、普通页面及侧栏使用磨砂卡片，增加细边框、16px 圆角和柔和阴影。日间使用暖色底，夜间使用暗色底。
- 普通卡片不透明度为 0.76，文章正文及页面正文为 0.86，背景模糊为 12px。不支持背景模糊时使用 0.94 和 0.96 的底色，避免背景干扰文字。
- 通过博客独立 CSS 实现，保留上游主题及其原有本地改动，避免改动第三方主题代码；独立阅读模式不使用卡片效果。

## 交付与验证

- 使用现有 npm 构建和 10 个页面的站点完整性检查。
- 浏览器核对日间、夜间卡片、透明页脚与 390px 手机正文，无水平溢出。
- 源代码保存于 `source` 分支；生成页面发布于既有 `main` 分支。发布使用普通快进提交，不重写远端历史。
- GitHub 访问使用本机已有代理，不修改全局 Git 配置或系统代理设置。
