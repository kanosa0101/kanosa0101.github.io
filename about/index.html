AI / 工程框架

PromptX · 智能提示词工程系统

聚焦大语言模型提示词工程（Prompt Engineering）与工作流协同，探索结构化 Prompt 编排、动态评估与自动化调优，为大模型应用落地提供工业级支持。

核心架构难点与突破：
  • 结构化 DSL 编排：支持复杂模板的分层继承与上下文动态注入
  • 动态评估闭环：多维度打分模型与自动化 Prompt 迭代调优
Prompt Engineering Python LLM Workflow
企业级 · 知识库

DocuMind · 智能文档与知识库系统

基于 Java 生态打造的结构化企业知识库系统，提供海量文档的分级归类、知识检索与协同管理，实现企业知识资产的高效组织与流转。

核心架构难点与突破：
  • 分级检索流水线：多格式文档自动化解析、切片与向量化语义检索
  • 企业级高可用：Spring Boot 微服务架构与细粒度权限协同管控
Java Spring Boot Knowledge Base RAG
移动跨端 · 交互

Moodisle (情绪岛屿) · 跨端客户端

基于 Dart / Flutter 打造的轻量级跨平台移动客户端，聚焦心理情绪记录与细腻的动效交互体验，探索跨端高性能渲染与本地持久化。

核心架构难点与突破：
  • 60fps 动效引擎：基于 Flutter 渲染管线的物理弹簧微动效交互
  • 本地离线持久化：端侧加密存储与轻量心理情绪状态机
Dart Flutter Mobile App State Machine
